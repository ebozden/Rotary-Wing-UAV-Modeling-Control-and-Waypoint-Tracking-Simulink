# Rotary-Wing UAV Modeling and Control

This project focuses on modeling, simulation, and control of a rotary-wing unmanned aerial vehicle (UAV) using MATLAB and Simulink.

## 🔧 Features

- Dynamic modeling of a rotary-wing UAV in Simulink  
- PID controller design for attitude and stability  
- Simple waypoint tracking algorithm  
- Optional visualization with FlightGear

## 📂 Project Structure

## 🚀 How to Run

1. Open `Simulink_Model.slx` in MATLAB Simulink.  
2. Run the simulation to observe the UAV dynamics.  
3. (Optional) Connect to FlightGear for real-time visualization.

## 📎 Requirements

- MATLAB R202x  
- Simulink  
- FlightGear (optional)

## 📘 Notes

This project is intended for academic and personal research. Further improvements can include advanced control methods (e.g. adaptive, LQR, or AI-based control).
